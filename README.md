# 🍀 KuroHub

> An all-in-one anime command center, multi-platform search router, and customizable browser dashboard.
---

## 🌟 Overview

**KuroHub** solves the fragmentation problem for anime fans. Instead of opening dozens of tabs to search for legal streams, check airing countdowns, read community episode threads, or find official soundtracks, KuroHub lets you search once and route anywhere.

It is designed to serve as a lightweight, lightning-fast browser homepage or daily launchpad, tightly integrated with the [KuroWatch](https://kuro2607.github.io/kuro/) tracking ecosystem.

---

## ✨ Features

- 🔍 **Universal Search Router:** Type an anime title once and open direct queries on:
  - **Legal Streaming:** Crunchyroll, Netflix, Ani-One Asia, Muse Asia, HIDIVE
  - **Trackers & Databases:** KuroWatch, AniList, MyAnimeList, Kitsu
  - **Community & Discussions:** Reddit (r/anime episode discussions), AnimeBytes, MyAnimeList Forums
  - **Media & Extras:** Official Soundtracks, Openings/Endings, Manga chapters, and Wallpaper galleries
- ⚡ **KuroWatch Deep Integration:** Direct 1-click access to weekly broadcast schedules, watch-order roadmaps, and personal watchlists on KuroWatch.
- 📌 **Customizable Quick Links & Bookmarks:** Add, reorder, or delete custom tool links directly from the UI. Everything persists locally via `localStorage`.
- 🌙 **Dark & OLED Optimized:** Minimalist dark mode with custom green accent lighting and high-contrast OLED options.
- 📱 **Fully Responsive & Zero Build Step:** Built with pure vanilla HTML5, CSS (Tailwind via CDN), and modern JavaScript. No node modules, bundlers, or build pipelines required.
